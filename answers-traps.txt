1) Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?

   Function arguments are passed in registers a0–a7.
   In main’s call to printf, the constant 13 is in register a2.


2) Where is the call to function f in the assembly code for main? Where is the call to g?
   (Hint: the compiler may inline functions.)

   There is no jal/jalr instruction calling f or g from main.
   The compiler inlined them and computed f(8)+1 at compile time,
   so main just loads the final value 12 directly into a1 (li a1,12),
   and never actually calls f or g.


3) At what address is the function printf located?

   printf is located at address 0x736 (shown as “jal ra,736 <printf>”).


4) What value is in the register ra just after the jalr/jal to printf in main?

   The jal at address 0x30 returns to the next instruction at 0x34,
   so ra holds 0x34 just after the call to printf.


5) Run the following code:

       unsigned int i = 0x00646c72;
       printf("H%x Wo%s", 57616, (char *) &i);

   What is the output?

   57616 in hex is 0xe110, so printf prints:

       He110 World

   ("H" + "e110" + " Wo" + "rld").


6) The output depends on the fact that the RISC-V is little-endian.  
   If the RISC-V were instead big-endian what would you set i to in order to yield the same output?
   Would you need to change 57616 to a different value?

   For big-endian, the bytes in memory must be 0x72 0x6c 0x64 0x00
   (the characters 'r','l','d','\0'). That corresponds to:

       i = 0x726c6400

   The 57616 argument does not depend on endianness, so it does not need to change.


7) In the following code, what is going to be printed after "y="?
   (Note: the answer is not a specific value.) Why does this happen?

       printf("x=%d y=%d", 3);

   After "y=", some unspecified/garbage value will be printed.
   The format string expects two integer arguments, but only one (3) is passed,
   so printf reads whatever happens to be in the next argument register/stack slot
   and prints that as y.
